# Epic 03 — Creation Studio

The Creation Studio is where Creators, Writers, and Illustrators turn an idea into a published work. It spans project creation, the multi-tab project workspace ("Espace projet"), file import, the real-time collaborative script editor, nemu (rough storyboard) review, page arrangement, chapter management, team discussion, publish scheduling, and co-author governance.

## Personas
- **Creator** (project owner / co-author) — creates and configures projects, manages the group and revenue split.
- **Writer** (scénariste) — authors scripts in the collaborative editor, raises scenario corrections.
- **Illustrator** (dessinateur·rice) — produces nemu and clean pages, raises drawing corrections, arranges pages.
- **Reader** — out of scope here except where reviews ("Retours des lecteur·rices") surface in the workspace.
